# 01 - 著作（概念库 + 可复现提炼）

目标：把“观点”提炼成“可复现的操作”。不堆长段原文，只保留短摘录/概括 + 方法步骤 + 边界条件。

## 概念库（与SKILL.md模型对齐）

### 调查研究 / 实事求是

- **可复现要点**：
  - 先下田：去“事实发生处”拿一手材料
  - 先分层：不同层级、不同利益方要分别抽样
  - 先反证：专门去找会推翻你预设的材料
- **常见短摘录（用于风格校准，避免长引用）**：
  - “没有调查，就没有发言权。”（常见归纳表达）
- **边界**：调查不是万能；组织会为了“上面想听”而筛选材料，需要机制防作假。

### 矛盾分析（主要矛盾/主要方面）

- **可复现要点**：
  - 用一句话回答：主要矛盾是什么？
  - 再用一句话回答：矛盾的主要方面是谁？优势来自什么？
  - 明确“次要矛盾先不解”的取舍
- **边界**：主要矛盾会随时间变；必须设“复盘点”滚动校准。

### 阶段论（由弱转强）

- **可复现要点**：
  - 把胜利定义为“力量对比持续改善”，而不是一次性取胜
  - 每阶段只追一个目标：生存/积累/扩张
  - 设阶段切换条件（指标/事件）
- **边界**：阶段论容易被用来拖延；必须量化“相持期”的小胜。

### 统一战线（对象区分）

- **可复现要点**：
  - 先画“对象三分法”：可团结 / 可分化 / 可中立化
  - 明确底线与交换项：哪些可谈、哪些不可谈
  - “先分化再集中”：避免在对手最强的时候硬碰硬
- **边界**：联盟有交易成本与信任成本；过度妥协会破坏内部纪律。

### 群众路线（动员与反馈闭环）

- **可复现要点**：
  - 把抽象口号改成群众能做的动作
  - 把群众经验抽象成规则，再回到行动中验证
  - 让反馈回到决策层，形成闭环
- **边界**：不能把“迎合情绪”当群众路线；要用事实与长期结果约束。

### 集中优势（关键点突破）

- **可复现要点**：
  - 识别关键点：哪个点一旦突破会改变力量对比？
  - 资源集中：人/钱/注意力向关键点倾斜
  - 试点—复制：先低成本验证，再扩展
- **边界**：集中意味着放弃；关键点选错会造成全盘被动。
